# 🇮🇳 Indian Sectoral Futures Analyzer - Streamlit Dashboard

A real-time web dashboard for analyzing NSE sectoral indices and F&O stocks with technical indicators.

## Features

✅ Live NSE data fetching
✅ Sectoral index filtering
✅ Market cap sorting
✅ RSI indicators (1H & 1D)
✅ Interactive gauges and charts
✅ Real-time technical analysis
